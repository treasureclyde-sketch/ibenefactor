# Бот записи «Бенефактор» — Cloudflare Workers

Интерактивный Telegram-бот: здоровается по имени, задаёт 5 вопросов и присылает
владельцу готовую заявку. Бесплатно, **без карты**, работает 24/7.

Как это связано с сайтом:
1. В модалке человек вводит имя → жмёт кнопку.
2. Сайт зовёт воркер `POST /lead` → получает короткий код.
3. Открывается `t.me/<бот>?start=<код>` — этот тап разблокирует бота.
4. Бот пишет «Имя, здравствуйте!» и ведёт по вопросам, в конце шлёт заявку тебе.

> Почему тап обязателен: Telegram запрещает ботам писать первыми. Обойти нельзя —
> но после одного тапа всё работает как задумано.

---

## Шаг 1. Создать бота
В Telegram открой **@BotFather** → `/newbot` → получи **токен** (`12345:AA...`). Никому не показывай.

## Шаг 2. Узнать свой chat_id
Напиши боту **@userinfobot** (или @getmyid_bot) — он пришлёт твой numeric ID. Это `OWNER_CHAT_ID`.

## Шаг 3. Установить инструменты и создать хранилище
Нужен Node.js. Дальше в папке `worker/`:
```bash
npm install -g wrangler          # или: npx wrangler ...
wrangler login                   # войти в Cloudflare (регистрация бесплатна, карта не нужна)
wrangler kv namespace create KV  # создаст неймспейс и покажет id
```
Скопируй выданный `id` в `wrangler.toml` (заменить `PUT_YOUR_KV_ID_HERE`).

## Шаг 4. Прописать переменные и секреты
В `wrangler.toml` впиши свой `OWNER_CHAT_ID`. Затем:
```bash
wrangler secret put BOT_TOKEN         # вставь токен из BotFather
wrangler secret put WEBHOOK_SECRET    # придумай любую строку (необязательно, но лучше сделать)
```

## Шаг 5. Задеплоить
```bash
wrangler deploy
```
Получишь адрес вида `https://benefactor-bot.<твой>.workers.dev`. Запомни его.

## Шаг 6. Подключить вебхук Telegram
Открой в браузере (подставь токен, адрес воркера и тот же WEBHOOK_SECRET):
```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://benefactor-bot.<твой>.workers.dev/webhook&secret_token=<WEBHOOK_SECRET>
```
Ответ `{"ok":true}` — готово.

## Шаг 7. Связать с сайтом
В `index.html` (блок booking modal, вверху скрипта) впиши:
```js
const WORKER_URL='https://benefactor-bot.<твой>.workers.dev';
const BOT_USER='твой_бот_без_собачки';
```
Теперь кнопка «Записаться» открывает бота, и он ведёт диалог.

### Проверка
Открой сайт → «Записаться» → введи имя → «Продолжить в Telegram» → бот должен
поздороваться по имени и задать вопросы. В конце заявка придёт тебе в личку.

### Стоимость
Cloudflare Workers free plan: 100 000 запросов/день, KV бесплатно. Для записей — с запасом. Карта не нужна.

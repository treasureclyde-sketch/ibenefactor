# Бот записи «Бенефактор»

Телеграм-бот: ведёт человека по короткому сценарию (запрос → имя → возраст → город → контакт)
и присылает готовую заявку тебе в личку. Для демо ставим на твой аккаунт («твинк»).

## 1. Создать бота (2 минуты)

1. В Telegram открой **@BotFather** → `/newbot` → задай имя и юзернейм (например `benefactor_zapis_bot`).
2. BotFather пришлёт **токен** вида `12345:AA...`. Это секрет — никому не показывай, в код/чат не вставляй.

## 2. Узнать свой chat_id

Запусти бота (см. ниже) и напиши ему `/myid` — он ответит числом. Это `OWNER_CHAT_ID` —
адрес, куда будут падать заявки.

## 3. Переменные окружения

Бот читает два значения из окружения (не из кода):

| Переменная       | Что это                                  |
|------------------|------------------------------------------|
| `BOT_TOKEN`      | токен из BotFather                        |
| `OWNER_CHAT_ID`  | твой chat_id (куда слать заявки)          |

Локально: скопируй `.env.example` → `.env` и впиши значения (файл `.env` в git не попадает).

## 4. Запуск локально (для проверки)

```bash
cd bot
npm install
npm start
```

Пока команда работает — бот живой. Открой `t.me/твой_бот`, напиши `/start`.
Сначала узнай `/myid`, впиши в `.env`, перезапусти — и заявки начнут приходить тебе.

## 5. Хостинг 24/7 (чтобы работал всегда)

Бот — обычный Node-сервис на long polling, поэтому подходит любой хостинг. Варианты:

- **Railway** (`railway.app`) — самый простой: New Project → Deploy from GitHub repo →
  Root Directory `bot` → во вкладке **Variables** добавь `BOT_TOKEN` и `OWNER_CHAT_ID` → Deploy.
  Крутится 24/7. Нужна карта для верификации (даже на бесплатном лимите).
- **Fly.io** — есть бесплатный лимит, но нужен CLI + карта для верификации.
- **Обычный VPS** (~200–300 ₽/мес) — полный контроль: `npm install`, затем
  `pm2 start bot.js` (pm2 держит бота живым и перезапускает при падении).

> Секреты (`BOT_TOKEN`, `OWNER_CHAT_ID`) всегда вставляй **в переменные окружения хостинга**,
> а не в код и не в репозиторий.

## Связь с сайтом

Кнопки «Записаться» на сайте могут вести прямо в бота: в `index.html` в блоке booking modal
впиши юзернейм бота в `BOT_USER` — и кнопка откроет `t.me/бот?start=<пакет>`
(бот поймёт, на какой пакет пришёл человек: `diag`, `8`, `15`, `25`).
